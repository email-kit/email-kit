# @email-kit/cli

The `email-kit` command: set up a project, compile TSX email templates to HTML and plain text,
check them against email-client, accessibility and compliance rules, and preview them in the
studio.

```sh
npm create email-kit       # set up a project (coming soon)
npx email-kit compile      # after install
```

> **Status:** pre-release. This package name is reserved; the first usable version ships with
> milestone M1.1. See the [PRD](https://github.com/email-kit/email-kit/blob/main/docs/prd.md).
