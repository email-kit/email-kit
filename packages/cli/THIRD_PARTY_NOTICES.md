## Unicode CLDR

`dist/cli.js` bundles data from the Unicode Common Locale Data Repository (CLDR) 47, through the
`cldr-core` package: plural rules (`supplemental/plurals.json`), parent locales
(`supplemental/parentLocales.json`) and likely subtags (`supplemental/likelySubtags.json`). Modules
that `email-kit compile` generates contain plural-rule functions and locale data derived from it.
